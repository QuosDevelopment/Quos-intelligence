# QUOS Intelligence

AI agent that builds websites, apps, tools, and answers questions.

## Features
- Build websites
- Build apps
- Build tools
- Search Google
- Generate content
- Deploy to Vercel

## Setup
1. Clone repo
2. Install dependencies
3. Add API keys (Gemini, OpenSerp, GitHub, Vercel)
4. Run `npm start`

## Tech Stack
- Express.js
- Gemini API
- OpenSerp
- GitHub
- Vercel
